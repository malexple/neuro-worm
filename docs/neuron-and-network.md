# Нейрон и нейронная сеть в neuro-worm

Документ описывает, что такое нейрон (в живой клетке и в нашей модели), из чего он состоит, как работает, и как из нейронов собрана сеть червя *C. elegans*. Сначала идёт глоссарий: термины, которые встречаются в коде, логах и других документах проекта.

## 1. Глоссарий

### Биология

| Термин | Что это |
|---|---|
| Нейрон | Электрически возбудимая клетка, которая принимает сигналы, обрабатывает их и передаёт дальше. |
| Сома | Тело клетки: в ней ядро; здесь «складываются» входные сигналы. В модели ей соответствует потенциал `v`. |
| Дендрит | Ветвистый отросток, принимающий входные сигналы от других клеток. В модели это входящие синапсы. |
| Аксон | Длинный отросток, по которому уходит выходной сигнал. В модели это список исходящих синапсов `out`. |
| Синапс | Контакт между нейронами, через который передаётся сигнал. Бывает химический и электрический. |
| Пресинаптический / постсинаптический нейрон | Передающий и принимающий нейрон в паре. |
| Нейромедиатор | Вещество, которое передающий нейрон выбрасывает в химический синапс. Примеры: глутамат (GLU), ацетилхолин (ACh), ГАМК (GABA). |
| Возбуждающий синапс | Повышает потенциал принимающего нейрона, приближая его к срабатыванию. |
| Тормозной синапс | Понижает потенциал принимающего нейрона, мешая срабатыванию. |
| Gap junction (щелевой контакт) | Электрический синапс: прямой канал между клетками, ток течёт в обе стороны без задержки. |
| Мембранный потенциал | Разность зарядов внутри и снаружи клетки. Это главная переменная нейрона. |
| Потенциал действия (спайк) | Короткий импульс «всё или ничего», который запускается, когда потенциал достигает порога. |
| Градуальный потенциал | Плавный сигнал, амплитуда которого зависит от силы стимула (нет порога «всё или ничего»). У большинства нейронов *C. elegans* сигнал преимущественно градуальный, но есть исключения: нейрон `AWA` генерирует настоящие спайки. |
| Порог | Значение потенциала, при котором нейрон срабатывает. |
| Рефрактерный период | Короткий интервал после спайка, когда нейрон не срабатывает снова. |
| Утечка (leak) | Постепенное возвращение потенциала к покою, если новых входов нет. |
| Нейромодуляция | Сигнал, который не передаёт информацию, а меняет состояние сети (голод, страх, сон): вещество (серотонин, дофамин, октопамин) выбрасывается в среду и действует на многие клетки. |
| Закон Дейла | Правило: один нейрон выделяет один тип медиатора, поэтому знак его синапсов (возбуждает или тормозит) одинаков. У реальных клеток знак ещё зависит от рецептора на принимающей клетке. |
| Коннектом | Полная схема связей между нейронами организма. |
| Сенсорный нейрон | Принимает сигнал из среды (запах, соль, боль). |
| Интернейрон | Промежуточный нейрон между сенсорным и моторным. |
| Моторный нейрон | Управляет движением (мышцами). |
| ON / OFF нейрон | ON возбуждается, когда стимул растёт; OFF, когда стимул падает. |
| Хемотаксис | Движение по градиенту химического вещества (к еде или от опасности). |
| Частотное кодирование (rate coding) | Информация несётся частотой спайков: сильнее стимул, выше частота. |
| Фоновая активность | Редкие случайные спайки (несколько Гц) даже без входа. |
| Адаптация | Снижение частоты спайков при постоянном сильном стимуле (нейрон «устаёт»). |
| Пластичность | Способность связей менять силу в зависимости от опыта. |
| Гомеостаз | Поддержание активности нейрона около целевого уровня: если спайков слишком много, порог растёт; если мало, падает. |

### Модель и код

| Термин | Что это |
|---|---|
| Тик | Шаг симуляции, 1 мс модельного времени. |
| Шаг мира | 10 тиков (10 мс): раз в столько движется червь. |
| LIF | Leaky integrate-and-fire: нейрон с утечкой, который накапливает вход и срабатывает по порогу. |
| `v` | Потенциал нейрона. Покой равен 0, порог около 1 (безразмерные единицы). |
| `kick` | Добавка к потенциалу от случайного фонового или сенсорного события. |
| `stimulusHz` | Частота внешнего стимула для сенсорного нейрона (Гц). |
| `baselineHz` | Частота фонового шума (Гц). |
| `fatigue` | Усталость: растёт после каждого спайка, временно повышает порог. |
| `thresholdOffset` | Сдвиг порога от гомеостаза. |
| `lesioned` | Флаг отключения нейрона (абляция). |
| `Synapse.scale` | Множитель веса синапса; именно он меняется при обучении. |
| `Sign` | Явный знак синапса (+1 или -1) из таблицы предсказаний; перекрывает знак по медиатору. |
| `PlasticityManager` | Класс, который меняет `scale` по правилу R-STDP. |
| Eligibility trace (след пригодности) | Затухающая «метка» синапса: недавно совпали спайки до и после, награда может прийти позже. |
| STDP | Правило пластичности, зависящее от порядка спайков до и после синапса. |
| R-STDP | STDP с третьим фактором (наградой): метка синапса превращается в изменение веса только при награде. |
| Награда | Знаковый сигнал (аналог дофамина), который задаёт внешний код. |
| EMA | Экспоненциальное скользящее среднее: сглаживание ряда чисел. |
| Моторный пул | Группа моторных нейронов, чья средняя частота задаёт движение (вперёд, назад, поворот). |
| Арена, тор | Двумерный мир 200×200 без стен: выйдя за край, червь появляется с противоположной стороны. |
| Seed | Начальное число генератора случайных чисел: даёт воспроизводимость. |
| Геном (в эволюции) | Набор чисел (усиление сенсоров, коэффициенты движения, масштабы связей), который подбирает эволюционный алгоритм. |
| Фитнес | Число, которое эволюция минимизирует (например, расстояние до еды). |
| Абляция | Отключение нейронов, чтобы выяснить, без каких из них поведение пропадает. |
| Условный стимул (CS) / безусловный стимул (US) | В ассоциативном обучении: нейтральный сигнал (соль) и значимый (еда, награда). |
| Парная / непарная группа | Обучение, где CS и US даются вместе, или порознь. |
| SE (стандартная ошибка) | Оценка разброса среднего; различие меньше двух-трёх SE считаем шумом. |
| Снапшот | Сохранённое обучаемое состояние сети (пороговые сдвиги и масштабы синапсов). |

## 2. Нейрон в живой клетке

Нейрон состоит из трёх основных частей. **Дендриты** принимают входные сигналы, **сома** (тело клетки) их суммирует, **аксон** передаёт результат дальше. Когда мембранный потенциал достигает порога, нейрон генерирует потенциал действия, который по аксону идёт к синапсам. На химическом синапсе импульс заставляет нейрон выбросить нейромедиатор, а принимающая клетка по-разному на него отвечает: возбуждается или тормозится. Электрические синапсы (gap junction) передают ток напрямую.

У *C. elegans* всего около 300 нейронов, у каждого свой постоянный набор связей. Большинство из них передаёт сигнал не спайками «всё или ничего», а плавными градуальными потенциалами, но есть исключения (нейрон `AWA` генерирует спайки). Наша модель для простоты везде использует спайки.

## 3. Нейрон в модели

Модельный нейрон (класс `Neuron`) это LIF-нейрон со следующим составом.

| Часть | В модели |
|---|---|
| Сома | потенциал `v`, порог `threshold`, утечка с постоянной `tau` |
| Дендриты | буфер входящих сигналов: сумма весов синапсов, пришедших в этот тик |
| Аксон | список исходящих синапсов (`out`) с весом, задержкой и знаком |
| Электрические контакты | список `gaps` (проводимость связи) |
| Адаптация | `fatigue` |
| Гомеостаз | `rateHz` (скользящая частота) и `thresholdOffset` |
| Нейромодуляция | `releases` (какое вещество выбрасывает при спайке) и `stressSensitivity` (как сильно стресс снижает порог) |

### Что происходит с нейроном за один тик

Значения безразмерные: покой 0, порог 1.

1. Усталость затухает: `fatigue -= fatigue / fatigueTau`.
2. Потенциал обновляется: `v = v + (vRest - v) / tau + входы + ток_gap`. Утечка тянет `v` к покою, входы сдвигают его вверх (возбуждение) или вниз (торможение).
3. С вероятностью `(baselineHz + stimulusHz) * 0,001` добавляется случайный толчок `kick`. Так работают фоновая активность и сенсорный стимул: частота стимула становится вероятностью толчка за тик.
4. Если нейрон в рефрактерном периоде, `v` сбрасывается и счётчик убывает.
5. Иначе, если `v >= эффективный_порог`, нейрон срабатывает.

Эффективный порог:

```
порог = threshold * (1 - stressSensitivity * стресс) + fatigue + thresholdOffset
```

Значит, порог повышают усталость и гомеостаз, а понижает стресс (рост октопамина).

### Спайк

При срабатывании:

- `v` сбрасывается в `vReset`, и включается рефрактерный период (2 тика);
- `fatigue` растёт на `fatigueInc`;
- нейрон передаёт сигнал по своим синапсам (через буфер с задержкой в тиках);
- если нейрон модулятор, он добавляет вещество в глобальное поле.

### Параметры по умолчанию

| Параметр | Значение | Смысл |
|---|---|---|
| `tau` | 20 | постоянная утечки, тиков |
| `vRest`, `vReset` | 0, 0 | покой и значение после спайка |
| `threshold` | 1,0 | базовый порог |
| `kick` | 1,5 | величина случайного толчка |
| `refractoryTicks` | 2 | рефрактерный период |
| `fatigueInc`, `fatigueTau` | 0,25, 500 | рост и затухание усталости |
| `baselineHz` | 3 (в экспериментах 1) | фоновая частота |
| гомеостаз | цель 3 Гц, скорость \(2 \cdot 10^{-5}\) | сдвиг порога в диапазоне от -0,6 до +3,0 |

### Частота как язык

Нейрон передаёт силу стимула частотой спайков: чем сильнее стимул, тем чаще срабатывает. Следующий нейрон получает больше входов в единицу времени и тоже возбуждается сильнее. Адаптация делает так, что при постоянном стимуле частота снижается, и нейрон лучше реагирует на изменения, чем на постоянный фон. Гомеостаз не даёт сети ни замолчать, ни «взорваться».

## 4. Синапсы

### Химические

Сигнал передаётся с задержкой 1 тик. Вклад в потенциал принимающего нейрона за один спайк:

```
знак * масштаб_k * число_контактов * scale
```

- **Знак.** Если в таблице есть явный `Sign` для пары, берётся он. Иначе знак задаёт медиатор передающего нейрона: GLU и ACh возбуждают, GABA тормозит.
- **Вес.** Число срезов электронной микроскопии из коннектома, умноженное на общий коэффициент \(k_{chem} = 0{,}1\).
- **`scale`.** Множитель, который меняется при обучении (изначально 1).

Тормозные синапсы нужны, чтобы сеть не уходила в «эпилептический» режим, когда один спайк запускает лавину.

### Электрические

Ток между нейронами A и B течёт по разности их потенциалов:

```
I = g * (v_B - v_A)
```

Расчёт идёт по значениям прошлого тика, чтобы не было зависимости от порядка обхода. Для устойчивости сумма проводимостей на нейрон не должна превышать 0,5, поэтому общий коэффициент \(k_{gap} = 0{,}0009\).

### Нейромодуляторы

Вместо адресного синапса нейрон выбрасывает вещество в общее поле (серотонин, дофамин, октопамин). Концентрация затухает на 1% за тик. Чувствительные нейроны меняют свои параметры (например, порог снижается под стрессом).

## 5. Нейронная сеть

### Из чего она строится

Сеть создаётся из двух файлов: `connectome.csv` (кто с кем и с каким весом, и необязательный знак) и `neuron_types.csv` (медиатор и класс каждого нейрона). В итоге 300 нейронов, 3707 химических пар и 1087 пар gap junction.

### Шаг симуляции

За один тик симулятор делает следующее:

1. Берёт из буфера задержек вход каждого нейрона на текущий тик.
2. Сохраняет потенциалы всех нейронов (чтобы gap-токи считались по прошлому состоянию).
3. Для каждого нейрона вычисляет ток gap junction, обновляет потенциал (раздел 3) и проверяет срабатывание.
4. Спайки раскладывает в буфер: получатель увидит их через заданное число тиков.
5. Обновляет гомеостаз (скользящую частоту и сдвиг порога).
6. Затухает поле нейромодуляторов.
7. Вызывает хук конца тика, через который работает пластичность.

Отключённый нейрон (`lesioned`) в этом цикле пропускается: он молчит, его gap-контакты не проводят ток.

### Детерминизм

Случайные числа берутся из генератора с фиксированным seed, поэтому одинаковые данные и seed дают одинаковые спайки.

### Что получается на выходе

Сеть сама по себе даёт паттерны спайков. Чтобы они стали поведением, нужны сенсоры и мотор: мир кормит сенсорные нейроны частотой стимула, а средняя частота моторных пулов превращается в скорость и поворот.

## 6. Пластичность и обучение

Обучаются только множители `scale` выбранных синапсов. Правило R-STDP:

```
след_до    += -след_до / tau + (нейрон до сработал)
след_после += -след_после / tau + (нейрон после сработал)
e          += (после сработал ? след_до : 0) - A_минус * (до сработал ? след_после : 0)
e          -= e / tau_e
scale      += eta * награда * e        (scale ограничен от 0,05 до 10)
```

Идея в том, что совпадения спайков «помечают» синапс (`e`), а изменение веса происходит, только когда приходит награда. Награда это знаковое число, которое задаёт внешний код: например, производная запаха или импульс «еда».

## 7. Червь в мире

| Элемент | Как устроено |
|---|---|
| Арена | тор 200×200 |
| Запах и соль | \(c = A e^{-d/\lambda}\), \(\lambda = 60\) |
| Сенсоры | два боковых датчика, смещённых на 2 единицы от оси тела |
| Кодирование | `AWA` кодирует рост запаха, `AWC` работает как OFF (падение запаха), `ASEL/ASER` кодируют соль, `ASH` боль |
| Моторные пулы | вперёд `VB/DB`, назад `VA/DA`, повороты `SMDD/RMDD` против `SMDV/RMDV` |
| Движение | скорость `baseSpeed + speedGain * (вперёд - назад)`; поворот `turnGain * (дорсальный - вентральный)` |
| Питание | в радиусе 3 единиц от еды червь останавливается |
| Шаг мира | 10 тиков сети на один шаг движения |

### Как проверялось поведение

- **Хемотаксис.** Параметры червя подбираются эволюцией; метрика это расстояние до еды. Сравнение идёт со «слепым» червём, у которого сенсоры отключены.
- **Абляции.** Отключаются классы нейронов по одному; ущерб измеряется расстоянием до еды и долей находок.
- **Обучение.** Награда идёт через `PlasticityManager`. Для ассоциативного обучения сравнивают парную группу с непарной, с группой «только награда» и с вариантом без награды.

## 8. Что в модели упрощено

- Везде спайки, хотя у большинства нейронов *C. elegans* реальный сигнал градуальный.
- Нет мышц и тела: поворот и скорость берутся прямо из частот пулов нейронов.
- Знаки синапсов приняты из предсказаний по экспрессии генов (Fenyves et al. 2020), а не измерены.
- Для 32 нейронов медиатор неизвестен, по умолчанию принят глутамат.
- Постоянный толчок вперёд `baseSpeed` задан снаружи, он не вырастает из нейронов.
- Роли сенсоров (`AWA` как ON, `AWC` как OFF) приняты из общего знания и сверены не со всеми источниками.
