# neuro-worm

Симулятор нервной системы *C. elegans* на Java 21 (Gradle, Groovy DSL). Вместо Transformer здесь спайковая сеть, построенная по реальному коннектому червя: возбуждающие, тормозные и электрические синапсы, нейромодуляторы, адаптация, гомеостаз и пластичность. Червь живёт в 2D-мире, чувствует запах и соль, ползёт к еде и учится по награде. Есть JavaFX-визуализация с интерактивным отключением нейронов.

Статус: исследовательский прототип. Часть выводов получена на Python-прототипах (они воспроизводят Java-модель) и отмечена в разделе «Ограничения».

## Модули

| Модуль | Назначение | Зависимости |
|---|---|---|
| `neuro-worm-core` | LIF-нейрон, синапсы, симулятор (шаг 1 мс), загрузчик коннектома, пластичность, снапшоты (интерфейс) | нет |
| `neuro-worm-world` | 2D-арена (запах, соль, боль), тело червя, моторные пулы, эволюционные эксперименты, сцена хемотаксиса | `core` |
| `neuro-worm-persistence` | JSON-реализация снапшотов (Jackson) | `core` |
| `neuro-worm-viewer` | JavaFX: арена, след, сетка нейронов, поиск и отключение нейронов | `core`, `world` |

Базовый пакет: `ru.mcs.neuroworm`.

## Модель

- **Нейрон.** Leaky integrate-and-fire, шаг 1 мс, рефрактерный период 2 тика, адаптация через `fatigue`, пуассоновский фон (1 Гц в экспериментах), сенсорный стимул `stimulusHz`, флаг `lesioned` (отключение). Детерминизм через `SplittableRandom` с фиксированным seed.
- **Синапсы.** Химические (знак задаёт медиатор пресинаптического нейрона: ACh и GLU возбуждают, GABA тормозит; задержка 1 тик), электрические gap junction (явный Эйлер, сумма проводимостей на нейрон не больше 0,5), нейромодуляторы как глобальные поля (серотонин, дофамин, октопамин) с затуханием 0,99 за тик.
- **Гомеостаз.** Сдвиг порога по скользящей частоте (EMA 1000 тиков) к целевым 3 Гц, \(\eta = 2 \cdot 10^{-5}\), диапазон сдвига от -0,6 до +3,0.
- **Пластичность.** R-STDP с eligibility trace на множителе `Synapse.scale` (класс `PlasticityManager`); награда задаётся снаружи, знаковая.
- **Снапшоты.** `Snapshots.capture/apply` сохраняют и восстанавливают сдвиги порогов и масштабы синапсов; `JsonSnapshotCodec` пишет их в JSON.
- **Мир.** Тор 200×200, запах и соль \(c = A e^{-d/\lambda}\), два боковых сенсора. Шаг мира 10 мс (10 тиков ядра).
- **Моторика.** Пулы по классам: вперёд `VB/DB`, назад `VA/DA`, повороты `SMDD/RMDD` против `SMDV/RMDV`. Скорость и поворот по EMA частот пулов.
- **Сенсоры.** `AWA` кодирует концентрацию и её рост, `AWC` работает как OFF-нейрон (реагирует на падение запаха), `ASEL/ASER` кодируют соль (рост и падение), `ASH` реагирует на боль.

## Данные

Коннектом: Cook et al. 2019, SI-5 «Connectome adjacency matrices» (исправленная версия июля 2020), гермафродит. Из таблиц взяты только нейроны.

- 300 нейронов (`CANL`, `CANR` в таблицах без синапсов, поэтому не вошли), 3707 пар химических связей, 1087 пар gap junction.
- Веса в таблице это число срезов электронной микроскопии. Масштабы: \(w = k_{chem} \cdot n\) с \(k_{chem} = 0{,}1\), \(g = k_{gap} \cdot n\) с \(k_{gap} = 0{,}0009\) (ограничено нейроном `ALA`).
- `neuron_types.csv`: GABA у 26 нейронов (`DD`, `VD`, `RME`, `AVL`, `DVB`, `RIS`), ACh у 158 нейронов (по таблице Loer и Rand на основе Pereira et al. 2015). Остальные 116 по умолчанию `GLU` с флагом `inferred`.

Формат файлов в `src/main/resources`:

```
connectome.csv:    Source,Target,Type,Weight     (Type: S = химический, G = gap)
neuron_types.csv:  Neuron,Neurotransmitter,Class (Class: SENSORY|INTER|MOTOR|MODULATORY)
```

Данные академические, при публикации ссылайтесь на Cook et al. 2019 и WormAtlas.

## Сборка и запуск

```
./gradlew test                                       # все тесты
./gradlew :neuro-worm-viewer:run                     # визуализация (окно открывается через 5-10 с)
./gradlew :neuro-worm-world:run                      # эволюция хемотаксиса (Evolution)
./gradlew :neuro-worm-world:runPlasticity            # эволюция правила обучения
./gradlew :neuro-worm-world:runPlasticityOdorOnly    # то же, награда только от запаха
./gradlew :neuro-worm-world:runAblation              # абляция найденного правила
./gradlew :neuro-worm-world:runControl               # контроль с задержкой награды
./gradlew :neuro-worm-world:runConditioning          # ассоциативное обучение (соль + награда)
./gradlew :neuro-worm-world:runConditioningControls  # контрольные группы к нему
./gradlew :neuro-worm-world:runConditioningStats     # те же группы на 60 seed со стандартными ошибками
./gradlew :neuro-worm-world:runAblationScan          # отключение каждого класса нейронов по очереди, ablation.csv
```

Длинные запуски используют все ядра, 5-40 минут.

### Viewer

Слева арена (зелёный фон это запах, круг это еда, жёлтая линия это след, красная черта это направление червя). Справа сетка из 300 нейронов: синие сенсорные, серые интернейроны, красные моторные; вспышка означает спайк. Управление: `Pause`, `Reset` (новый seed), ползунок скорости от x0,1 до x50. Клик по клетке отключает или возвращает нейрон. В поле `Neuron` можно ввести имена или префиксы (`AWC`, `AIY, AIB`); найденные клетки выделяются жёлтой рамкой, `Lesion` и `Restore` отключают и возвращают их, `Clear lesions` снимает все отключения.

## Результаты

Расстояние в единицах арены, меньше значит ближе к цели.

| Эксперимент | Результат |
|---|---|
| Покой, гомеостаз включён | среднее 3,6 Гц, максимум 11,8 Гц |
| Реакция на запах (отношение к покою) | `AIY` ×2,86, `AVA` ×1,36, `AVB` ×1,61 |
| Эволюция хемотаксиса (9 генов), 20 новых seed | с запахом 11,8, слепой 76,6 (старт 60) |
| Регресс: обучающая сцена | 17,4 против 74,5 |
| Регресс: новая сцена (дистанция около 85) | 14,1 против 67,2 |
| Покалеченный червь (масштаб сенсор-интернейроны 1,0 вместо 6,5) | 52,6 |
| Эталон с эволюционным масштабом | 16,0 |
| R-STDP, найденное правило | 9,0 |
| Награда только от запаха | 12,3 |
| Она же с обратным знаком | 78,5 |
| Награда с задержкой 3 с / 10 с | 33,5 / 30,5 |

Вывод по пластичности: правило подстраивает усиление и частично использует связь по времени между активностью и наградой. Это самонастройка.

### Ассоциативное обучение

Соль как условный стимул, награда как безусловный. Эволюция правила с фитнесом, требующим безразличия наивного червя и отсутствия эффекта у контролей. Оценка на 60 новых seed, пять независимых обучений.

| Группа | Расстояние до соли |
|---|---|
| случайный уровень (слепой) | 80,3 ± 3,4 |
| наивный | 82,0 ± 3,1 |
| парная (соль и награда вместе) | 57,2 ± 2,8 |
| непарная | 70,4 ± 2,9 |
| только награда | 72,7 ± 3,0 |
| парная, награда отключена (rewardGain = 0) | 82,0 ± 3,1 |

Приобретение притяжения (около -25 к наивной) и специфичность (-13...-15 к контролям, 3-4 стандартные ошибки) подтверждены; эффект идёт через веса, потому что без награды результат равен наивному. Остаётся неспецифичный остаток в контролях (около 10 единиц).

### Абляции

В viewer при отключении `AWCL` и `AWCR` червь не находит еду (4 и более запусков, расстояние 84-99 при старте 60). Это согласуется с тем, что эволюция сделала `AWC` ключевым путём. Систематический перебор классов (`runAblationScan`) в работе.

## Ограничения

- Часть экспериментов предварительно проверялась в Python (numpy). Они повторяют Java-модель, но числа в таблицах взяты из Java-логов.
- Знаки синапсов заданы только по медиатору пресинаптического нейрона. У живого червя знак зависит от рецептора, и доля тормозных связей выше (по литературе около 4 к 1 для возбуждающих к тормозным).
- 116 нейронов получили `GLU` по умолчанию; часть из них моноаминергическая.
- У реального червя нейроны в основном не генерируют классических спайков. LIF здесь упрощение.
- `baseSpeed` (постоянный толчок вперёд) задан снаружи, а не выращен из нейронов.
- Роль `AWC` как OFF-нейрона принята из общего знания и в этой сессии не сверялась с первоисточниками; вывод о её необходимости относится к нашей модели, а не к настоящему червю.
- Классы моторных нейронов: `A` назад, `B` вперёд (проверить по первоисточнику).
- Эволюционные геномы зашиты в код и тесты константами.
- Абляция в viewer острая: гомеостазные сдвиги настроены на целую сеть и не перестраиваются после отключения.
